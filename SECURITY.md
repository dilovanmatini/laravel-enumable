# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a vulnerability

If you discover a security issue, please email **dilovan@lelav.com** instead of opening a public GitHub issue.

Include:

- A description of the vulnerability
- Steps to reproduce
- Any potential impact

You can expect an initial response within 72 hours.
